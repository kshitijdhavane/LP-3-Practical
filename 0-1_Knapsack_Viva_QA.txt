# 0/1 Knapsack Problem -- DAA Viva Questions and Answers

## 1. Basic Concepts

**Q1. What is the 0/1 Knapsack Problem?**\
It is an optimization problem in which we select items with given
weights and values to maximize total value without exceeding the
knapsack capacity.

**Q2. Why is it called 0/1 Knapsack?**\
Each item has only two choices: 0 means do not select it, and 1 means
select it. Fractions of items are not allowed.

**Q3. What is the objective?**\
To maximize the total value while keeping the total weight within the
capacity.

**Q4. What are the inputs?**\
- `n`: number of items - `wt`: weight of each item - `val`: value/profit
of each item - `W`: maximum knapsack capacity

**Q5. Give a real-life example.**\
Choosing products to pack in a bag with a weight limit while maximizing
their total value.

**Q6. Which algorithmic technique is used?**\
Dynamic Programming.

**Q7. Can an item be selected more than once?**\
No. Each item can be selected at most once.

**Q8. What is an optimization problem?**\
A problem in which we seek the best feasible solution, such as maximum
profit or minimum cost.

## 2. Dynamic Programming

**Q9. What is Dynamic Programming?**\
Dynamic Programming solves a problem by breaking it into smaller
subproblems and storing their results to avoid repeated calculations.

**Q10. Why is Dynamic Programming suitable for 0/1 Knapsack?**\
The problem has overlapping subproblems and optimal substructure.

**Q11. What are overlapping subproblems?**\
The same smaller subproblems occur repeatedly during computation.

**Q12. What is optimal substructure?**\
An optimal solution can be constructed using optimal solutions to
smaller subproblems.

**Q13. What is a DP table?**\
A table that stores the maximum value achievable for different item
counts and capacities.

**Q14. What is the size of the 2D DP table?**\
`(n + 1) × (W + 1)`.

**Q15. What are the base conditions?**\
`dp[0][w] = 0` and `dp[i][0] = 0`. With zero items or zero capacity, the
maximum value is zero.

**Q16. What are the two choices for each item?**\
Include the item or exclude the item.

**Q17. What is tabulation?**\
A bottom-up DP method that fills a table iteratively, starting from
smaller subproblems.

**Q18. What is memoization?**\
A top-down DP method that uses recursion and stores previously computed
results.

**Q19. Which approach does the practical program use?**\
Bottom-up Dynamic Programming, also called tabulation.

## 3. Recurrence Relation

For `i` items and capacity `w`:

-   If `i == 0` or `w == 0`, then `dp[i][w] = 0`.
-   If `wt[i - 1] > w`, the current item cannot fit:
    `dp[i][w] = dp[i - 1][w]`
-   Otherwise:
    `dp[i][w] = max(val[i - 1] + dp[i - 1][w - wt[i - 1]], dp[i - 1][w])`

**Q20. Explain the recurrence relation.**\
If the current item is too heavy, we exclude it. Otherwise, we compare
the value obtained by including it with the value obtained by excluding
it, and choose the larger result.

**Q21. Why do we use `max()`?**\
To choose the better of the include and exclude options.

**Q22. Why do we use `i - 1` to access `wt` and `val`?**\
Python lists use zero-based indexing, while the DP table's item rows
start at 1.

**Q23. Why does the include case use the previous row?**\
Using `dp[i - 1]` ensures that the current item is not used again, which
enforces the 0/1 rule.

## 4. Python Code Questions

**Q24. What does this statement do?**

``` python
dp = [[0 for x in range(W + 1)] for x in range(n + 1)]
```

It creates a two-dimensional DP table filled with zeros.

**Q25. Why is the table created with `W + 1` columns?**\
To represent capacities from 0 through W, inclusive.

**Q26. Why is the table created with `n + 1` rows?**\
To represent item counts from 0 through n, inclusive.

**Q27. What does `for i in range(1, n + 1)` do?**\
It processes each item, from item 1 through item n.

**Q28. What does `for w in range(1, W + 1)` do?**\
It considers every capacity from 1 through W.

**Q29. Explain `if wt[i - 1] <= w`.**\
It checks whether the current item can fit in the current capacity.

**Q30. What does `dp[n][W]` represent?**\
The maximum value obtainable using all n items with capacity W.

**Q31. Why initialize the table with zeros?**\
Because the answer is zero when there are no items or no capacity.

## 5. Complexity

**Q32. What is the time complexity of the 2D DP solution?**\
`O(n × W)`, because the algorithm fills approximately n × W table
entries.

**Q33. What is the space complexity?**\
`O(n × W)`, because it stores a two-dimensional table of that size.

**Q34. Can space be optimized?**\
Yes. A one-dimensional DP array can reduce space to `O(W)`. Capacities
must be processed in descending order to prevent reusing an item.

**Q35. What is the brute-force time complexity?**\
`O(2^n)`, because every item has two possibilities: include or exclude.

**Q36. Is `O(n × W)` polynomial time?**\
It is pseudo-polynomial time because it depends on the numeric value of
W, not just the number of bits used to represent W.

**Q38. Difference between Greedy and Dynamic Programming?**\
Greedy makes a locally best choice at each step. Dynamic Programming
solves and stores subproblems, then combines their results. Greedy does
not always give the optimal answer for 0/1 Knapsack.

**Q39. Difference between memoization and tabulation?**\
Memoization is top-down and usually recursive. Tabulation is bottom-up
and usually iterative.

**Q40. Can Greedy always solve 0/1 Knapsack optimally?**\
No. Choosing the item with the highest value-to-weight ratio can produce
a non-optimal result.

## 7. Tricky Questions

**Q41. What if all item weights are greater than the capacity?**\
The maximum value is zero, assuming all weights are positive.

**Q42. What if capacity is zero?**\
The maximum value is zero.

**Q43. What if there are no items?**\
The maximum value is zero.

**Q44. Can two items have the same weight or value?**\
Yes.

**Q45. Must the knapsack be completely full?**\
No. The objective is to maximize value, not necessarily to use all
capacity.

**Q46. Does the algorithm always select the item with the highest
individual value?**\
No. It selects the combination of items that gives the highest total
value within the capacity.

**Q47. Does input order affect the optimal value?**\
No. The optimal value remains the same, although the DP table and one
selected combination may differ.

**Q48. Can the algorithm handle a zero-weight item?**\
Yes, but the implementation and recurrence must handle it correctly. A
positive-value zero-weight item should be included.

## 8. Worked Example

Given:

  Item     Weight   Value
  ------ -------- -------
  1            10      60
  2            20     100
  3            30     120

Knapsack capacity: `W = 50`

The best selection is item 2 and item 3.

-   Total weight = `20 + 30 = 50`
-   Total value = `100 + 120 = 220`

**Maximum value = 220**
